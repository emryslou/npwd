# 0.0.3.2025.02.04
1. 支持命令 run， clear-data, version
2. run 支持 扫描指定目录的*文件*，或者 指定的*文件*
3. 支持监控文件下，项目空闲时周期新重新发送指定目录下的所有文件

---
1. 文件格式为
```
# 每行为一个完整的 JSON 格式数据
{ ... }
{ ... }
```
2. 每行JSON包含字段说明
```JSON
{
    "name": "说明性文字", # 必填
    "url": "网页URL地址", # 必填
    "blocks": [ # 必填 ，可为空数组
        {
            "name": "btc", # 名称
            "selector": "css 选择器"
        }
    ]
}
```
